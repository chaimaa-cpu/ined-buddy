# INED Buddy — Assistant Universitaire Intelligent

Chatbot type ChatGPT pour les étudiants MDO 1 de l'INED, déployé sur Netlify.

## ✨ Fonctionnalités

- 🇫🇷 Interface 100% française
- 🧠 Vrai LLM derrière (OpenAI / OpenRouter / Groq / DeepSeek)
- ⚡ Streaming mot par mot (effet ChatGPT)
- 💬 Mémoire conversation complète
- 📝 Rendu Markdown + coloration syntaxique du code
- 📋 Bouton "Copier" sur chaque bloc de code
- 🛑 Bouton Arrêter / 🔄 Bouton Régénérer
- 📚 Historique sauvegardé (localStorage)
- 🏷️ Renommage auto des conversations
- 🌙 Mode sombre / clair
- 🔐 Clé API sécurisée (côté serveur uniquement)
